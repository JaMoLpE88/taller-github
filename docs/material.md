# Material del taller

## Sesión 1: de cero a repositorio

1. Crear cuenta en GitHub.
2. Crear un repositorio público con README y licencia.
3. Clonar en local: `git clone https://github.com/TU-USUARIO/taller-github.git`.

## Sesión 2: trabajo con ramas

1. Crear una rama: `git switch -c mi-primera-rama`.
2. Editar, preparar y confirmar: `git add .` y `git commit -m "..."`.
3. Subir: `git push -u origin mi-primera-rama`.
4. Abrir un pull request y fusionar.

## Sesión 3: automatizar

1. Un workflow mínimo en `.github/workflows/ci.yml`.
2. Ver como el CI corrre en cada push.
3. Etiquetar la versión `v0.1.0` y publicar una release.
